# Tech Stack — airportiq

## Frontend

Static single-file chat page served by FastAPI at `/`, vanilla JS, no build step, no external scripts, follows
the system theme, talking to `POST /api/chat`. Voice (browser Web Speech API) is a bonus item (v5).

## Backend

- **Language / runtime:** Python 3.12, `src/app/` layout, uv (`uv.lock` committed), hatchling. Typer CLI:
  `agent serve | chat | eval | ingest | registry | profiles | verify | score`. `main()` forces UTF-8 stdout on Windows.
- **Agent framework:** Pydantic AI 2.63 (`pydantic-ai-slim[anthropic,google,typesafe,retries]`): `Agent` with
  `output_type=AnswerOut`, `FunctionToolset`, `UsageLimits(request_limit, cost_limit)`, `message_history`.
- **Models:** chain in `config/agent.yaml`: `anthropic:claude-sonnet-5-5` → `anthropic:claude-haiku-5-5` →
  `google-gla:gemini-2.5-flash` via `FallbackModel(fallback_on=[ModelAPIError, httpx2.HTTPError, truncated])`.
  No OpenAI (owner decision 1.11.2026). Per-model HTTP retries with the tenacity transport (429/5xx/network,
  Retry-After aware, capped); vendor SDK retries off; a model whose key is missing is skipped at startup. Model ids
  and `config/prices.yaml` verified at kickoff. Anthropic prompt caching of the static prefix on from v0.
- **Guard:** regex layer → anchored intro → `Screening(in_scope, injection)` by TypeSafe Jev (`typesafe:jev-latest`),
  fallback to Haiku on error or any field confidence < 0.7; keyword guard in `MODEL_MODE=test`. Refusals are fixed
  strings and spend nothing.
- **Budget:** SQLite ledger, monthly cap `BUDGET_USD` (10), reserve → settle → release; per-turn `cost_limit`
  0.25 USD / 16 requests; 20 req/IP/hour, 200/day.
- **API:** FastAPI + uvicorn: `/health`, `POST /api/chat`, `GET /api/stats` (admin token), `DELETE /api/sessions/{id}`.
  In-memory sessions (1 h TTL, LRU 500), one asyncio lock per session.
- **Scoring engine:** pure Python over DuckDB queries; component definitions, weights, capacity model parameters
  in versioned `config/scoring.yaml`; FAA profile rates in `config/capacity_profiles.yaml`.

## Database

- **DuckDB over Parquet snapshots committed to the repo:** `taf.parquet` (ops and enplanements per airport and
  fiscal year, history + forecast), `ontime_monthly.parquet` (per origin and month aggregates 2023–2025),
  `t100_annual.parquet` (per origin, year, domestic/international and long-haul flag: departures, seats,
  passengers), plus `manifest.json`. Ingest once locally, commit; deploys need no network.
- **SQLite** at runtime only for the spend ledger.
- **Registry** in `config/airports.yaml` (generated by `agent registry`, committed): FAA LID, IATA, ICAO, name,
  city, state, Census region and division, hub class, lat/lon, timezone, runway counts, longest runway, aliases.

## Data sources (public; keyless unless noted)

- **FAA Terminal Area Forecast 2025** (`taf.faa.gov/Downloads/APO100_TAF_Final_2025.zip`) — operations and
  enplanements per airport, history and forecast to 2050.
- **FAA CY2025 commercial-service enplanements** (xlsx) — hub class and enplanements; defines the universe.
- **OurAirports** `airports.csv`, `runways.csv` — identifiers, coordinates, runways.
- **BTS Airline On-Time Performance** (monthly PREZIP zips) — departures, delays, taxi-out, cancellations, distance.
- **BTS T-100 Segment, All Carriers** — seats, passengers, departures, distance, country; downloaded once by hand
  through the TranStats form (no scripted URL), raw CSV ignored, aggregate Parquet committed with provenance.
- **FAA Airport Capacity Profiles** (33 PDFs, 2014–2019) — hourly capacity rates per weather condition, extracted
  once by `agent profiles` into `config/capacity_profiles.yaml`.
- **FAA NAS status** (`nasstatus.faa.gov/api/airport-status-information`, XML) — live closures, ground stops,
  delay programs; cached 10 min.
- **OpenSky Network** (registered client, optional, v6) — aircraft currently around an airport.

## Other

- **Evals:** `evals/cases.yaml` (categories in_scope / off_topic / injection / false_positive / followup; fields
  expect, must_contain, must_not_contain, tools, prior_turns, max_chars) → `agent eval --repeat N --tag T --down
  <vendor> --model M` → `evals/results/T.{json,md}`; exit 0 pass / 1 fail / 2 flaky; grounding check on every number.
- **Tests:** pytest, offline; `FunctionModel`/`TestModel` fakes, `httpx2.MockTransport`; spec-coverage test
  enforces `test_criterion_<n>_<slug>` per acceptance criterion. Never patch the network.
- **CI:** GitHub Actions: ruff + pytest + offline eval smoke; `permissions: contents: read`; no keys.
- **Deployment:** Render Blueprint (`render.yaml`), python runtime, `uv sync --frozen --no-dev`, `/health` probe,
  secrets `sync: false`. Repo: public `ozeriyarin/airportiq`, commit straight to `main`.
- **Secrets:** env only (`.env.example`); `MODEL_MODE=test` for a keyless demo; provider-side spend limits set in
  each console (Anthropic, Google, TypeSafe) with the dates in the README.
- **Process tooling:** Agent OS v3 (`agent-os/`, `.claude/commands/agent-os/`), Claude Code, ruff.
